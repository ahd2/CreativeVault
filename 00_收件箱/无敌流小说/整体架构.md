# 第二卷 势起东域

视野开始步向整个东域。之前的小国只是小打小闹。这里开始接触东域的高层，包括四大古族（女主家算是没落的古族，所以实际辉煌的古族只有三家）之间的事和断道司的阴谋。断道司其实是要夺取四大古族的所有信物的。然后有一家古族其实投敌了。另外两家一家和主角比较相合，另一家其实看主角不顺眼，但是危急时刻也同仇敌忾了。

开始揭露反派势力断道司的阴谋。

# 第五卷 xx妖族

开启妖族的剧情。妖族这里我设想是类似纳塔那种情况，就是男主死后，其实妖族也出了变故，处于闭关锁国的情况。这样才能顺理成章的拖到男主剧情推进到这里。

不然按理说第三四卷下来男主已经名动天下了，妖皇不应该不来找他。

然后我设想的剧情是，类似绘梨衣一样。然后妖皇也是类似原神少女的人设。

然后目前其实已经快死了或者表面上死了。主打一个遗憾。

# 第六卷 终局

断道司boss的目的。我有一个初步想法，就是，他是希望把整个世界的修士全部消灭。然后只有他自己一个人拥有绝对的能力。这样才能给天下带来太平。一个绝对强权的人。

所以这个boss人设也要立起来。他不坏，但是他对所有修士一样残忍。普通修士是视普通人为蝼蚁，而他是视修士为蝼蚁。（甚至可以安排他更早和主角相遇）

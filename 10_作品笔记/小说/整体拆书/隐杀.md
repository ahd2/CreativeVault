# 《隐杀》总纲拆解

## 核心主题

前世顶级杀手重生后，试图逃离杀戮、获得普通人生，但过去的杀手世界不断追上来。他在日常、感情、危险和清算之间，寻找真正的自由。

## 阶段拆分

| 阶段 | 核心内容 | 阶段功能 |
|---|---|---|
| 楔子 | 前世杀手、凤凰、重生愿望 | 建立“自由”主题 |
| 重生童年 | 反杀杀手，回到黄家/叶家 | 改变命运，建立普通生活愿望 |
| 三人组建立 | 灵静、怀沙登场，童年日常 | 建立情感核心 |
| 校园日常与小危机 | 夏令营、学校、张雅涵等 | 在日常中展示隐藏强者爽点 |
| 三人小家庭 | 青春期、同居/共同生活、关系沉淀 | 让“普通生活”具体化 |
| 外部势力回潮 | 黑帮、裴罗嘉、炎黄觉醒等介入 | 杀手世界威胁日常 |
| 国际线升级 | 星梦号、月池薰、海外势力 | 展开主角暗面身份和战力 |
| 纽约救援 | 张雅涵线与裴罗嘉矛盾升级 | 主角从逃避转向主动对抗 |
| 东京清算与入狱 | 家明爆发、清算旧敌、入狱 | 主角低谷，普通生活破碎 |
| 四年后回归 | 出狱、重逢、终局 | 回答“自由与普通生活”主题 |

# 感悟

感觉这套逻辑可以内化。一个想要归隐的大佬，怎么牵扯入冲突呢？就要从他身边人入手，首先他身边人背景不凡。所以才会牵扯入大事。然后他又想要守护身边人。

但是这样，他身边人要怎么背景不凡呢？隐杀的方法是，主角的家族本身就有一定阶级。只不过主角是家族里不起眼的。

不过另一方面，这个又是这种归隐流专属的。

我看过这类小说，除了隐杀，其实合雪的一些都算是。
